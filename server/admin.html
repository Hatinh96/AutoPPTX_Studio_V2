Chọn thư mục gốc (vd «Data avatar»). Giữ nguyên cây thư mục con theo kênh. Tên file = mã RP, bỏ đuôi A / AA / _Ava (vd 1994HAIRA.jpg → 1994HAIR). Ảnh không đổi so với lần trước được bỏ qua; ảnh lớn được máy chủ thu nhỏ .
